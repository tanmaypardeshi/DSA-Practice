# CSES Problem Set

| Problem | Description |
| ------- | ----------- |
| [weird_algorithm.cpp](weird_algorithm.cpp) | Weird Algorithm (Collatz conjecture sequence) |
| [missing_number.cpp](missing_number.cpp) | Missing Number — find the missing number from 1 to n |
| [increasing_array.cpp](increasing_array.cpp) | Increasing Array — minimum moves to make array non-decreasing |
| [repititions.cpp](repititions.cpp) | Repetitions — find the longest repetition of a character in a string |
| [permutations.cpp](permutations.cpp) | Permutations — construct a permutation of 1..n with no two adjacent elements differing by 1 |
| [number_spiral.cpp](number_spiral.cpp) | Number Spiral — find the value at row x, column y in an infinite number spiral |
| [two_knights.cpp](two_knights.cpp) | Two Knights — count pairs of knights that do not attack each other on an n×n board |
| [two_sets.cpp](two_sets.cpp) | Two Sets — partition 1..n into two sets with equal sums |
| [bit_strings.cpp](bit_strings.cpp) | Bit Strings — count bit strings of length n (2^n mod 10^9+7) |
